# T1 Slice 4a: scaffold mw-session

Committed by the maintainer: the headless session could not write under
.claude/loop (protected path), so step 5 was finished by hand. The loop state
moved to ops/loop in the next commit.

## What changed
- crates/mw-session: new crate, deps exactly mw-crypto, mw-identity, mw-proto,
  thiserror. Contains only `pub mod machine;`, docs cite ADR-017 by section.
- Cargo.toml: workspace member added. Cargo.lock regenerated.
- xtask/check-machine-purity.sh: bans clock, thread, I/O, runtime and entropy
  tokens (including grouped and aliased imports), the private-key types
  Keypair, Keystore, SigningKey, the Signer trait, glob imports from mw_crypto
  and mw_identity, and #[path. Scans machine*.rs and machine*/ only.
  --self-test plants one line per banned token plus word-boundary controls and
  an impure driver.rs that must not be flagged.
