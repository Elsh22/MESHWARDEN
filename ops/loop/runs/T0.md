## 6. Choices the ADR didn't dictate (flag for maintainer)

1. Comments and string/char literals are blanked before matching, so
   wire-layout docs such as `frame.rs:85` `payload: [u8; payload_len]` do not
   trip the check. Raw strings (`r"..."`, `r#"..."#`) are not understood; none
   exist in `crates/mw-proto/src` today. Char-literal handling is a heuristic:
   for `'\''` the cursor lands on the closing quote, which the reviewer found
   harmless in every probe.
2. The check matches `u8` arrays only, per the task text. Arrays of other
   element types are not checked.
3. "as of <hash>" uses the queue Base `09dfd51`, not current HEAD. HEAD is
   `5294445`; the commits since the base touch dependencies, deny.toml, and the
   loop harness only.
4. The check covers `crates/mw-proto/src` only, matching the ADR-017 row.
   `.cursor/rules/crypto-boundary.mdc` says "any wire/spec struct", and
   `crates/mw-identity/src/node_id.rs:32` has `prefix: [u8; NODE_ID_PREFIX_LEN]`.
